Before you install

Links is a small independent project, not something from a large registered publisher, so Windows shows a caution screen the first time you open it — signed or not, it's just what an unfamiliar publisher looks like. It isn't a sign anything's wrong, and you only see it once.

Show me the Windows steps
Click More info on the blue screen, then Run anyway. That's it — Links opens normally from then on.
Show me the Linux steps
The AppImage isn't executable by default — that's normal for any AppImage, not specific to Links. Either right-click it → Properties → Permissions → allow executing, or from a terminal: chmod +x Links-*.AppImage. Then double-click (or run) it directly.
